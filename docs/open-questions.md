# 미결 사항과 충돌

이 문서는 초기 PDF 분석의 질문 이력입니다. 2026-10-10에 확정한 정책은 [기능 요구사항](requirements.md)의 6절과 7절을 따릅니다. 아래 질문을 현재 미결 상태로 해석하지 않습니다.

기능정의서 14쪽의 미결 항목 8개를 보존합니다. 아홉 번째 추적 질문은 같은 문서 안의 차단과 공동 프로젝트 권한 충돌입니다. 답을 임의로 정하지 않습니다.

| 번호 | 질문 | 원문 근거 | 필요한 결정 |
|---|---|---|---|
| Q1 | 타이머를 서버에 저장할까요? | 14쪽 | 기기 간 이어하기 범위 |
| Q2 | 카운터 ±1을 매번 전송할까요, 모아서 보낼까요? | 14쪽 | 동기화 시점과 충돌 처리 |
| Q3 | 신고 누적 시 자동 조치와 운영자 화면이 필요할까요? | 14쪽 | 운영 정책 |

## 추가 구현 전 질문

- V1-108은 로그인 없이 정책 문서를 조회합니다. 정책 버전·언어·활성 시점 응답 형식을 정해야 합니다.
- V1-604는 기록 수정·삭제를 작성자에게 허용합니다. done 상태에서 허용할지는 미정입니다.
- V1-902는 차단 시 프로젝트 초대 제거를 말하지만, 기존 초대의 양방향 삭제 범위를 확인해야 합니다.
- V1-505~507의 이관은 댓글·반응을 보존합니다. 댓글 권한과 이관 후 게시자 표시에 대한 정책을 확인해야 합니다.
- V1-201/207/208과 공동 프로젝트 조회의 경계를 API별로 정의해야 합니다.
- PDF의 17개 표 제안은 모델 초안입니다. 약관 동의 및 리프레시 세션 요구를 포함하는지 재검토가 필요합니다.
- 점(.) 허용 여부는 아이디 정규식 `^[a-z0-9_.]{4,20}$`를 기준으로 구현 전에 원문 표의 점 문자 표현을 확인해야 합니다.
